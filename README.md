# Employee Payroll Calculator

A C# application for calculating employee payroll information.

## Overview

This project provides a comprehensive solution for managing and calculating employee payroll. It handles various payroll calculations and employee data management efficiently.

## Features

- Employee payroll calculation
- Payroll data management
- Support for various compensation structures

## Technology Stack

- **Language**: C#
- **.NET Framework**: .NET (version as specified in your project)

## Getting Started

### Prerequisites

- .NET SDK installed on your system
- Visual Studio or Visual Studio Code (recommended)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/liewvk/EmployeePayrollCalculator.git
   cd EmployeePayrollCalculator
   ```

2. Restore dependencies:
   ```bash
   dotnet restore
   ```

3. Build the project:
   ```bash
   dotnet build
   ```

## Usage

Run the application with:
```bash
dotnet run
```
